# 📝 Todo List

A simple Todo List web application built using **Python** and **Flask**. This application allows users to add and delete tasks through a clean and user-friendly interface.

## 🚀 Features

- Add new tasks
- Delete completed tasks
- Simple and responsive UI
- Built with Flask
- HTML and CSS frontend

## 🛠️ Technologies Used

- Python
- Flask
- HTML5
- CSS3

## 📂 Project Structure

```
Todo_List/
│── app.py
│── static/
│   └── style.css
│── templates/
│   └── index.html
└── README.md
```

## ▶️ Installation

1. Clone the repository:

```bash
git clone https://github.com/srikarreddy5760/Todo_List.git
```

2. Navigate to the project folder:

```bash
cd Todo_List
```

3. Install Flask:

```bash
pip install flask
```

4. Run the application:

```bash
python app.py
```

5. Open your browser and visit:

```
http://127.0.0.1:5000/
```
